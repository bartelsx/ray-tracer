# Ray Tracer – Multithreaded Bunny Scene

A ray tracing engine written in C++, capable of rendering detailed 3D models like the Stanford bunny with high visual fidelity and performance.

## Features
- Multithreaded CPU ray tracing
- Soft shadows, reflection, and lighting
- High-performance rendering
- Realistic material rendering

## Technologies Used
- C++
- Multithreading
- Ray tracing algorithms

## How to Run
1. Clone the repository.
2. Build using your C++ compiler or IDE.
3. Run and enjoy the high-quality rendering output.
